# Optimisation-et-IA-en-Finance-Deribit-Options-Pricing-Hedging-
Plateforme quantitative d'options crypto sur Deribit. Pipeline de données, extraction du taux sans risque par parité Call-Put et Nelson-Siegel, calibration de la surface de volatilité SSVI, structuration de produits dérivés et optimisation de couverture Delta-Gamma-Vega neutre.
